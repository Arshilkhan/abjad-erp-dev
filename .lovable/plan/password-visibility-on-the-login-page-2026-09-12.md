# Password visibility on the login page

## Changes
- Add an eye icon inside each password field on the login and password-reset screens.
- Toggle between masked and visible text when the icon is pressed.
- Use an eye-off icon while the password is visible, with accessible labels and tooltips.
- Keep the existing sign-in, forgot-password OTP, validation, and navigation behavior unchanged.

## Verification
- Confirm the toggle works for the login password, new password, and confirmation fields.
- Confirm toggling does not clear values or submit the form.
- Check the controls on desktop and mobile widths.
