ABJAD ENGINEERING WORKS — ERP DATABASE RESET QUERIES
============================================================

Purpose
-------
These SQL statements are a reference for completely emptying the ERP's
business/transaction data while preserving login data, roles, permissions,
and application/company configuration.

IMPORTANT
---------
1. Run the statements in the order shown below.
2. Back up/export important data before running the reset.
3. These commands permanently delete data from the listed tables.
4. This file does NOT contain, store, or require admin-user credentials.
5. Do NOT run the protected-table TRUNCATE statements listed below.
6. Review the actual database schema before execution if the application
   has been modified since these queries were created.


STEP 1 — OPTIONAL BACKUP
------------------------
Before resetting the database, export/back up the tables you may need later,
especially invoices, customers, products, purchase orders, payments, and
related transaction data.

No SQL backup command is included here because the backup method depends on
your Supabase/database setup.


STEP 2 — CLEAR CHILD / TRANSACTION TABLES
------------------------------------------
TRUNCATE TABLE public.invoice_items RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.invoice_history RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.invoice_rejections RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.payments RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.customer_credits RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.stock_movements RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.rejected_inventory RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.purchase_order_items RESTART IDENTITY CASCADE;


STEP 3 — CLEAR PARENT TRANSACTION TABLES
----------------------------------------
TRUNCATE TABLE public.invoices RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.purchase_orders RESTART IDENTITY CASCADE;


STEP 4 — CLEAR MASTER DATA
--------------------------
TRUNCATE TABLE public.products RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.product_categories RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.customers RESTART IDENTITY CASCADE;

TRUNCATE TABLE public.vendors RESTART IDENTITY CASCADE;


STEP 5 — CLEAR RATE-LIMIT / MISC DATA
--------------------------------------
TRUNCATE TABLE public.rate_limits RESTART IDENTITY CASCADE;


STEP 6 — VERIFY THE RESET
-------------------------
Run this query after the reset:

SELECT 'invoices' AS table_name, count(*) FROM public.invoices
UNION ALL
SELECT 'customers', count(*) FROM public.customers
UNION ALL
SELECT 'products', count(*) FROM public.products
UNION ALL
SELECT 'purchase_orders', count(*) FROM public.purchase_orders;


Expected result
---------------
The business-data counts returned by the verification query should be 0.


PROTECTED TABLES — DO NOT TRUNCATE
-----------------------------------
The following tables must be preserved because they contain login data,
roles, permissions, or application/company configuration:

auth.users

public.profiles

public.user_roles

public.user_panel_permissions

public.company_profile

public.invoice_settings

public.invoice_configuration


INVOICE NUMBERING
-----------------
If the ERP uses an invoice prefix/year stored in public.company_profile and
you want to change the numbering after a reset, update the relevant prefix
or year in public.company_profile after the business data has been cleared.

No admin credentials are included in this file.


QUICK EXECUTION ORDER
---------------------
1. Optional backup/export
2. invoice_items
3. invoice_history
4. invoice_rejections
5. payments
6. customer_credits
7. stock_movements
8. rejected_inventory
9. purchase_order_items
10. invoices
11. purchase_orders
12. products
13. product_categories
14. customers
15. vendors
16. rate_limits
17. Run the verification SELECT


SAFETY NOTE
-----------
TRUNCATE ... CASCADE can remove rows from related tables through foreign-key
relationships. If the schema has changed, inspect the relationships and
current table list before executing the reset in production.
